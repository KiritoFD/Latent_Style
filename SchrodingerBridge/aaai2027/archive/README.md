# Archive

This directory holds non-active local review and intermediate artifacts that are
kept only for traceability.

Active paper-facing entry points should stay in the main `aaai2027/` root:

- current frozen `VLM` board
- current summary figures
- current mainline evidence board
- current final paper text/assets

What belongs here:

- superseded `VLM` snapshot history
- smoke outputs
- one-off scratch review files
- logs that are not current decision inputs
