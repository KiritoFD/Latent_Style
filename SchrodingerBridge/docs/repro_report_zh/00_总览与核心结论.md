## 当前方法定位

当前方法不是传统 arbitrary style transfer，也不是 CycleGAN/CUT 式 unpaired image translation。更准确的论文定位是：

```text
fast latent-space multi-style artistic transfer
```

核心故事应收束为：

```text
在 256 latent 空间中学习 style-conditioned probability flow / bridge，
用 SWD 约束终端风格分布，
用 kinetic regularization 保持内容结构，
用 style-id / spatial prior 提供多风格可扩展能力。
```

## 理论核心摘要

当前方法可以理解为一个在 VAE latent 空间中学习的、由目标风格条件控制的轻量 Schrodinger Bridge / probability-flow 近似。给定内容 latent `z_0` 和目标风格 `s`，模型不直接生成图像，而是预测一个速度场：

```text
v_theta(z_t, t, s)
```

推理时从内容 latent 出发沿速度场积分，得到风格化终点：

```text
z_1 = z_0 + integral_0^1 v_theta(z_t, t, s) dt
```

训练目标里，`terminal SWD` 扮演“终点分布约束”：它要求生成终点的 patch/feature 分布接近目标风格域；`kinetic loss` 扮演“最小形变约束”：它限制整条路径不要为追求风格而过度移动，从而保内容；`style spatial prior + semantic cross-attention` 扮演“多风格条件 transport map”：它把 style id 转成可学习的空间风格场，再用语义注意力把该风格场注入内容结构。

因此本文方法的理论叙事不是“一个普通 attention 风格迁移网络”，而是：

```text
在低维 latent 空间中，用风格分布约束和动能正则学习一条
content-preserving、style-conditioned 的近似最优传输路径。
```

这也解释了主要实验现象：

| 现象 | 理论解释 |
|---|---|
| 去掉 terminal SWD 后内容很好但风格弱 | 没有终点分布约束，bridge 退化为近似 identity flow |
| 去掉 kinetic 后 raw style 可高但内容崩 | 缺少路径动能约束，transport 允许过度形变 |
| K2 / entropy gate 指标偏内容保真 | 更强路径约束压制了不确定区域的风格迁移 |
| step size 增强能提 style 但伤 LPIPS | 积分路径走得更远，本质是在牺牲最小形变假设 |
| color / Gumbel transport 不宜主线 | 局部硬颜色匹配提升表面风格，但破坏全局内容一致性 |

当前最可靠的论文 claim 不是“raw CLIP-style 全面超过 SaMST”，而是：

```text
Ours 在 perceptual quality、LPIPS content preservation、HF-patch texture realism、
style-content trade-off 上优于 SaMST；SaMST raw style/content/SSIM/edge 很强，
但存在 muddy / grain-like texture artifacts。
```

## 当前最重要实验结论

### 1. K1 vs K2

K1 原始配置更容易获得高 raw CLIP-style：

```text
K1 original epoch7: CLIP-S 0.7161, LPIPS 0.4514, EC 0.3928
K1 original epoch8: CLIP-S 0.7167, LPIPS 0.4615, EC 0.3859
```

K2 更偏内容保持和 LPIPS：

```text
K2 repro epoch8: CLIP-S 0.6964, CLIP-C 0.8351, LPIPS 0.4247, EC 0.4007
K2 weighted epoch8: CLIP-S 0.7049, CLIP-C 0.8355, LPIPS 0.4184, EC 0.4100
```

解释：K1 更像 style-releasing setting，K2 更像 content-preserving setting。论文中如果讲质量/干净/内容保持，K2 系列更有利；如果讲 raw style，需要 K1 或推理增强/后期降 K。

### 2. 手动类别权重

最初手动权重：

```text
content weights = [photo 1.35, Hayao 1.25, monet 0.85, vangogh 0.85, cezanne 0.85]
target weights  = [photo 0.80, Hayao 1.35, monet 1.05, vangogh 1.05, cezanne 1.05]
```

对 K1 总体负面，对 K2 总体正面。K2 weighted 主要改善 photo-to-art：

| 方向 | Δstyle | Δcontent | ΔLPIPS | ΔEC |
|---|---:|---:|---:|---:|
| photo→Hayao | +0.0458 | +0.0159 | -0.0094 | +0.0290 |
| photo→monet | +0.0024 | +0.0187 | -0.0256 | +0.0179 |
| photo→vangogh | +0.0125 | +0.0044 | -0.0201 | +0.0202 |
| photo→cezanne | -0.0202 | +0.0264 | -0.0447 | +0.0175 |

结论：类别权重不是普适增强。它对 K2 的 photo-to-art 有价值，但 Cezanne style 会被压低。

### 3. 40 组权重 sweep

40 组为：

```text
20 个 category sampling recipes x K={1,2}
每组训练 8 epoch，每个 epoch 都评估 strict 750
总计 320 个 evaluated checkpoints
```

最佳 EC：

```text
K2_r00_balanced_default epoch3:
CLIP-S 0.6980, CLIP-C 0.8727, LPIPS 0.3777, EC 0.4343
```

重要结论：K2 balanced default 在短期综合指标上已经很强；复杂权重不一定优于 balanced。类别权重更适合做 domain-specific trick，而不是默认主策略。

### 4. 理论开关验证

新增并验证了三个开关：

| 开关 | 配置 | 结论 |
|---|---|---|
| Sinkhorn routing | `model.semantic_attn_routing_mode="sinkhorn"` | 提升内容/LPIPS/EC，但 raw style 降一点 |
| Entropy-gated kinetic | `bridge.kinetic_entropy_gate_weight>0` | 最有效的稳定性开关，EC 最好 |
| Gumbel color transport | `bridge.color_transport_mode="gumbel_hard"` 且 `w_color>0` | raw style 略升，但内容/LPIPS 损失过大，不建议主线 |

最佳短验证：

```text
Entropy gate 5.0 epoch1:
CLIP-S 0.6916, CLIP-C 0.8804, LPIPS 0.3684, EC 0.4368
```

### 5. SaMST 的正确解读

SaMST 不是失败 baseline。它 raw style、raw content、SSIM、Edge-F1 都强：

```text
SaMST strict:
CLIP-S 0.7194, CLIP-C 0.8193, LPIPS 0.4664, EC 0.3839
```

但视觉上有 muddy / grain-like artifacts。普通内容指标会偏向它，所以需要 artifact-sensitive 指标：

| 指标 | Ours epoch7 | SaMST strict | 结论 |
|---|---:|---:|---|
| MUSIQ ↑ | 49.2059 | 36.0950 | Ours 感知质量明显更好 |
| MANIQA ↑ | 0.4057 | 0.3139 | Ours 更好 |
| DISTS-content ↓ | 0.2477 | 0.2943 | Ours 更好 |
| HF-Patch-KID ↓ | 4.1694 | 6.7598 | Ours 高频纹理更像真实风格 patch |
| FFT slope error ↓ | 0.5473 | 1.0536 | Ours 频谱形态更自然 |
| Gram micro ↓ | 0.0798 | 0.0947 | Ours 浅层纹理统计更好 |

论文表述建议：

```text
SaMST obtains strong raw style and structure scores, but exhibits structured
grain/muddy texture artifacts. Our method improves perceptual quality and
artifact-sensitive texture realism while maintaining a better style-content
trade-off.
```

## 目前推荐主线

当前如果要继续冲击论文主结果，推荐顺序：

1. 以 `S-add__K-1_C-0_W-20_Col-0 epoch7` 作为视觉主线和原始 best raw-style 参照。
2. 以 `K2 balanced / K2 weighted` 作为 content-preserving / EC 主线。
3. 对 `max_integration_horizon` 和 `semantic_paint_gain` 做轻量 style-release 实验。
4. 不把 `w_color` 或 `gumbel color` 放进主线。
5. 对 SaMST 使用 artifact-sensitive 指标，不用 SSIM/Edge-F1/FID/KID 作为 ours 胜出依据。
