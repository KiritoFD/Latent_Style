## 2. 复现 Ours 主模型

### 2.1 推荐主配置

当前最可信的主线配置来自：

```text
S-add__K-1_C-0_W-20_Col-0/config.json
```

注意：不要随意改基础配置。之前白化结果的主要风险来自对配置和推理路径的非对齐修改。新实验应复制该配置到新目录后，只改实验变量和 `checkpoint.save_dir`。

### 2.2 训练命令

建议复制配置后运行，例如：

```powershell
Copy-Item .\S-add__K-1_C-0_W-20_Col-0\config.json .\my_repro_k1\config.json
```

手动确认 `my_repro_k1/config.json` 中：

```json
{
  "checkpoint": {
    "save_dir": "./my_repro_k1"
  }
}
```

然后运行：

```powershell
py -3 run.py --config .\my_repro_k1\config.json
```

### 2.3 推理与评估所有 epoch

建议评估所有 epoch，而不是只看最后一轮：

```powershell
py -3 run_evaluation.py .\my_repro_k1 `
  --output .\my_repro_k1\full_eval `
  --batch_size 20 `
  --max_src_samples 30 `
  --max_ref_compare 50 `
  --max_ref_cache 256 `
  --ref_feature_batch_size 64 `
  --num_steps 12 `
  --step_size 1.0
```

如果需要测试更强推理，可输出到新目录，避免覆盖：

```powershell
py -3 run_evaluation.py .\S-add__K-1_C-0_W-20_Col-0 `
  --output .\S-add__K-1_C-0_W-20_Col-0\full_eval_step125 `
  --batch_size 20 `
  --max_src_samples 30 `
  --num_steps 12 `
  --step_size 1.25
```

现有结论是：`step_size=1.25` 可提高 raw CLIP-style，但 LPIPS 下降明显，不适合作为默认主线。

## 5. 理论开关验证

### 5.1 已实现开关

| 开关 | 配置项 | 作用 |
|---|---|---|
| Sinkhorn Attention | `model.semantic_attn_routing_mode="sinkhorn"` | 将单边 softmax routing 改成近似双随机 routing |
| Sinkhorn 迭代数 | `model.semantic_sinkhorn_iters` | 控制双随机归一化强度 |
| Entropy-Gated Kinetic | `bridge.kinetic_entropy_gate_weight` | 对 attention 高熵区域增强动能约束 |
| Hard/Gumbel Color Transport | `bridge.color_transport_mode="gumbel_hard"` | 将局部颜色 transport 从软重心变为硬匹配近似 |
| Gumbel 温度 | `bridge.color_gumbel_tau` | 控制 hard color transport 的采样锐度 |

### 5.2 生成配置

```powershell
py -3 prepare_theory_switch_validation.py
```

### 5.3 运行验证

```powershell
py -3 run_theory_switch_validation.py
```

### 5.4 只收集结果

```powershell
py -3 run_theory_switch_validation.py --collect_only
```

核心输出：

| 文件 | 说明 |
|---|---|
| `theory_switch_validation/theory_switch_validation_all_epochs.csv` | 所有开关、所有 epoch 的结果 |
| `theory_switch_validation/theory_switch_validation_best_by_experiment.csv` | 每个开关的最佳结果 |
| `theory_switch_validation/theory_switch_validation_report.md` | 结论报告 |

当前结论：

```text
Entropy gate 和 Sinkhorn 可以改善 EC、content、LPIPS；
但 raw CLIP-style 会下降。

Color / Gumbel color 可以略提 raw style；
但会伤 content 和 LPIPS，不建议作为主线。
```

### 6.2 SaMST 的评价注意事项

SaMST 不应简单描述为结构失败。当前肉眼观察与指标结果更一致的判断是：

```text
SaMST 结构轮廓保留强，但输出存在均匀微颗粒 / dithering / 全局糊化问题。
标准 SSIM、Edge-F1、CLIP-content 会偏向奖励它。
```

因此论文中应使用：

```text
LPIPS
CLIP-style
CLIP-content
KID / FID / CLIP-FID
Gram style loss
ArtFID
EC plot
stroke-grain / chroma artifact diagnostics
user study
```

而不是只用内容结构指标判断胜负。

## 9. 推荐论文主线使用结果

当前最稳主线不是单纯最高 CLIP-style，而是三条线并行：

| 用途 | 推荐使用 |
|---|---|
| 质量主表 Ours | `S-add__K-1_C-0_W-20_Col-0 / epoch_0007` |
| EC / 内容-风格均衡分析 | `weight_sweep_40` 中 `K2_r00_balanced_default epoch_0003` |
| 消融完整模型 | `ablation_destructive_7epoch / D0_full_correct_7ep` |
| SaMST 对比 | `samst_strict`，但需配合 artifact / grain 指标和人评 |

建议论文表述：

```text
Ours 在 raw CLIP-style 上接近 SaMST，
在 LPIPS 和整体风格分布指标上更稳；
SaMST 在标准结构指标上很强，但存在明显微颗粒和全局糊化 artifact，
需要额外 artifact diagnostics 与 user study 评估。
```
