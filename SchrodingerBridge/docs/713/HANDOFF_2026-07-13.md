## 5. Diagnosis

The target objective is already style-heavy in HF:

```text
LL       = 0.7 * content_LL + 0.3 * AdaIN(content_LL -> style_LL)
LH/HL/HH = target_style bands
```

The bottleneck is the information route:

```text
baseline route:
style_id -> style_memory -> cross-attention

useful route:
target image -> DWT HF -> pooled per-subband code -> HF residual velocity -> LH/HL/HH

unsafe route:
target image -> DWT HF spatial maps -> HF residual maps
```

What the probes prove:

1. The network can use target-HF information: raw spatial HF raises DINO-S/CLIP-S strongly.
2. Raw target spatial maps are not acceptable: DINO-C collapses and LPIPS increases.
3. Pooled per-subband codes are the current usable middle ground.
4. More epochs alone are not the main lever: the 15-epoch HF-delta curve is below the 6-epoch subband route.
5. Content-anchor placement is safe but does not improve the frontier.
6. Cross-attention/style memory should be described as auxiliary, not as the main style injector.
7. Removing style memory entirely is not the fix: the no-memory subband run makes target-HF the clean live route in probes, but loses DINO-S, DINO-C, CLIP-S, and off-DINO-S in full eval. Style memory is a useful coarse prior; it needs to be bounded or decomposed, not deleted.
8. Direct residual-direction auxiliary supervision is not the fix: it raises mean residual/desired cosine from 0.158 to 0.322, but lowers DINO-S, DINO-C, CLIP-S, LPIPS, and off-DINO-S relative to subband-only.
9. Gradient/info-flow probe: the target image is strong as the supervised HF target but weak as a condition input. Under the actual FM-HF objective, condition-path gradients into target-style LH/HL/HH are only about `2.5%/1.3%/0.5%` of the target-construction gradients.
10. Simple route widening is not enough: cross-orientation mixing and target-current pooled-code deltas are live and safe, but neither changes residual direction or improves DINO-S/CLIP-S/content together.

CFG note: previous CFG observations are confounded with style delta heads, DWT routing, HH head availability, and larger gates. Do not claim CFG itself improves content without a matched control.

## 6. Current Claims and Non-claims

Claims that are currently supported:

- DINO-S is the primary style metric; CLIP-S is secondary.
- WEAVE is a balanced learned method, not the best method on every axis.
- StyleAligned is a high-style/content-collapse point.
- Latent-WCT shows wavelet statistics alone are insufficient.
- The best current architecture probe is `target_hf_subband_ft6`.
- `target_hf_subband_texture_ft6` is the safer alternate if off-DINO-S and DINO-C matter more than headline all-pairs DINO-S.

Claims not yet supported:

- Do not claim the HF-route probe is the new main-table model until full D5/P2A/R5 reruns are complete.
- Do not claim raw spatial HF is a valid style gain.
- Do not claim CFG is a proven content fix.
- Do not claim the worktree is clean.

## 8. Method-writing Guidance

Use this framing:

| Pathway | Role | Evidence |
|---|---|---|
| Structure path | LL mostly preserves content. | Spatial shortcuts and LL over-control damage content. |
| Style statistics path | Endpoint AdaIN and target-HF codes inject style. | AdaIN scaling and HF probes improve DINO-S. |
| Transport path | Rectified flow produces content-aware motion. | Latent-WCT alone is weak; raw stats alone are insufficient. |

Avoid old language that says DINO-S `0.48` is a fundamental limit. The better reading is narrower:

> Under the old SAT route, style saturates around this region because target-image HF does not have a clean non-spatial route into HF velocity heads. Opening that route gives modest but real improvements; raw spatial opening proves capacity but fails content.
