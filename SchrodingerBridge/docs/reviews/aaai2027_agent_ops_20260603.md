## Operating rules

1. Only `Linnaeus` should own live remote experiment execution.
2. Only the main thread should edit `paper_aaai2026.tex` unless a lane is
   explicitly reassigned for a bounded paper patch.
3. `Ampere`, `Darwin`, and `Carver` are support and pressure lanes. They
   produce memos, checklists, or review artifacts, not silent manuscript drift.
4. All standing lanes must keep ownership disjoint:
   - `Ampere` -> `docs/references/`
   - `Darwin` -> `docs/reviews/` claim-theory audit
   - `Carver` -> `docs/reviews/` adversarial gates
   - `Linnaeus` -> remote experiment artifacts

## Review-lane separation rule

The standing lanes are not the same thing as a full formal review cycle.

The standing lanes:

1. maintain continuity in literature, theory, remote execution, and adversarial
   pressure;
2. surface evidence gaps early;
3. reduce silent drift between code, experiments, and paper wording.

Formal review closure still requires independent review-cycle evidence as
tracked in:

- `docs/reviews/aaai2027_review_registry.csv`
- `docs/reviews/aaai2027_review_score_log.csv`
