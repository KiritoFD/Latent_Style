## 关键发现

### 1. SWD梯度非零但极小且正交
- ||∇_v SWD|| = **0.044** (非零，但极小)
- cos(∇SWD, v_target) = **-0.024** (基本正交!)
- SWD@v=0 = 0.467

**结论**: SWD梯度确实存在，但方向与v_target正交，SWD不提供任何有效梯度信号。

### 2. 排序绝对稳定
- ε=1e-5: 变化率=0%
- ε=1e-4: 变化率=0%
- ε=1e-3: 变化率=0%
- ε=1e-2: 变化率=0%

**结论**: 排序在v=0附近完全稳定。即使扰动到0.01（远大于估计的临界值0.003），排序仍未变化。这意味着投影值间距比预期大得多，或者SWD计算使用了非标准投影。

### 3. Loss Landscape: 极小值在s=1.0，不在s=0.16！

| s | FM | SWD | Total |
|---|-----|-----|-------|
| 0.00 | 1.512 | 0.467 | 5.248 |
| 0.16 | 1.069 | 0.400 | 4.268 |
| 0.50 | 0.378 | 0.308 | 2.844 |
| 1.00 | 0.000 | 0.000 | 0.000 |
| 2.00 | 1.512 | 0.869 | 8.462 |

**结论**: Loss landscape的全局极小值在s=1.0（正确解），模型应该收敛到s=1.0。

## 理论修正

### 原假设 (推翻)
- ~~SWD梯度=0 → v=0是局部极小值 → 模型陷入平凡解~~
- ~~排序稳定性导致梯度平坦区~~

### 新假设
**模型无法表示v_target**，不是因为loss landscape有问题，而是因为：
1. Style信号太弱 (gate=0.05) → 模型学不到style-specific的velocity
2. Endpoint head容量太小 → 模型输出的是style-agnostic的velocity
3. 模型输出的是E[v_target | x, t]（条件期望）而非v_target(x, t, style)
4. 条件期望的幅度远小于style-specific的v_target

### 新的修复方向
1. **强化style信号**: gate=0.3, 更多style tokens
2. **增大endpoint head容量**: 更多层, 更大hidden dim
3. **增加skip connection控制**: 可学习门控α per layer
4. **NSWD仍然有用**: 增大SWD梯度使其方向不完全是正交的随机噪声
