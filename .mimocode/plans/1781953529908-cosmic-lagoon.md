# Plan: FiLM Endpoint Heads — 修复白化问题 (H4)

## 数学假说 H4

**假说**: 当前 endpoint head 的 style 调制方式（输出端加法偏移）太弱——style 只影响输出，不重塑 head 内部的特征表示。FiLM (Feature-wise Linear Modulation) 在 head trunk 内部做仿射调制，让 style 重塑每一层的特征空间，从而产生更强的 target-facing endpoint 运动。

**数学形式**: 对 feature maps $h \in \mathbb{R}^{C \times H \times W}$ 和 style embedding $s$:
$$\text{FiLM}(h; s) = (1 + \gamma(s)) \odot h + \beta(s)$$
其中 $\gamma(s) = W_\gamma s + b_\gamma$, $\beta(s) = W_\beta s + b_\beta$，零初始化保证训练起点是恒等变换。

**与加法偏移的关键区别**:
- 加法: $y = f_{\text{head}}(h) + g(s)$ — style 只通过加法路径影响输出
- FiLM: $y = f_{\text{head}}((1+\gamma) \odot h + \beta)$ — style 重塑 head 内部每个后续层的输入

**验证指标**: alpha(t=0) > 0.30 (当前 0.1633), high_alpha(t=0) > 0.10 (当前 -0.0501), style_sensitivity > 5.0 (当前 8.75)

## 实验流程

### Phase 1: Smoke Test (~30s)
1. `git add` + `git commit` 代码改动
2. `git push` 到 remote
3. SSH remote, `git pull`
4. 运行 smoke: `launch_remote_620_spatial_bridge.py --config configs/620_spatial_bridge_film_smoke.json --task-name 620_film_smoke1`
5. 运行 hypothesis probe: `probe_620_hypothesis_metrics.py` on smoke checkpoint
6. **Gate**: alpha(t=0) > 0.0 且 style_sensitivity > 1.0

### Phase 2: Formal Short Run (~15min)
- 如果 smoke 通过: 正式跑 3 epochs
- 运行 fog probe: `probe_620_fog_path.py`
- **Gate**: endpoint_img_std/source_img_std > 0.90

### Phase 3: Full Run (~2hr)
- 8 epochs 全量训练 + full eval
- **目标**: clip_style >= 0.72

### 反馈循环
- 如果 alpha < 0: FiLM 未学习 → 增大 `endpoint_style_hidden_dim` 或添加第二层 FiLM
- 如果 alpha > 0.5 但 clip_style < 0.72: 检查正交残差 → 可能需要 loss 调参
- 如果 style_sensitivity < 1.0: FiLM 可能梯度消失 → 调整初始化或学习率

1. `py_compile` 检查语法

3. Hypothesis probe 确认 alpha 方向
4. Fog probe 确认白化签名消失
5. Full eval 确认 clip_style >= 0.72
