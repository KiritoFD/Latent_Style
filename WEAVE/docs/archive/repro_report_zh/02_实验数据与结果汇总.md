## 2. 统一评估协议

### 2.1 strict 750

当前大多数 ours/baseline 使用：

```text
source styles = photo, Hayao, monet, vangogh, cezanne
target styles = photo, Hayao, monet, vangogh, cezanne
source samples per source style = 30
total outputs = 5 x 5 x 30 = 750
```

生成和评估由：

```text
run_evaluation.py
src/utils/run_evaluation.py
```

执行。

### 2.2 核心指标

| 指标 | 方向 | 作用 |
|---|---:|---|
| CLIP-style | ↑ | 输出图像与目标风格语义/域的对齐 |
| CLIP-content | ↑ | 输出图像与源内容语义对齐 |
| LPIPS-content | ↓ | perceptual content preservation |
| EC product | ↑ | `CLIP-style x (1 - LPIPS)`，style-content trade-off |
| SSIM-Y | ↑ | 亮度结构相似度，但对 SaMST 不足以判断 artifact |
| Edge-F1 / Edge-IoU | ↑ | 边缘结构重叠，但容易被纹理边缘误导 |
| MUSIQ / MANIQA | ↑ | no-reference perceptual quality |
| DISTS-content | ↓ | 感知结构/纹理距离 |
| HF-Patch-KID | ↓ | 高频 patch 分布是否像真实 style |
| FFT slope error | ↓ | 频谱形态是否异常 |
| Gram micro | ↓ | 浅层 VGG Gram 风格纹理差异 |
| KID / FID / CLIP-FID | ↓ | 分布距离，但当前 750 协议下不适合作 ours 胜出主证据 |

## 10. 当前实验结论摘要

1. 如果目标是 raw style：K1 late epoch 或 color loss 可以抬 style，但 LPIPS/内容会受损。
2. 如果目标是综合 EC：K2 balanced / entropy-gated kinetic / Sinkhorn routing 更好。
3. 如果目标是论文主线：Ours 最稳的 claim 是 perceptual quality + style-content trade-off，而不是 raw CLIP-style SOTA。
4. SaMST 必须作为强 baseline 看待，不能简单说失败；要用 artifact-sensitive metrics 解释其问题。
5. 下一步最值得做的是推理 horizon / semantic paint gain / K schedule，而不是继续调 naive color loss。
