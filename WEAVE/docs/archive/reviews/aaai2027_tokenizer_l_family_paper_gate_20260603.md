## Why the boundary is this narrow

The reported correlations support only a limited reading:

- tokenizer to executed geometry is only moderate:
  - `corr_tokenizer_l2_to_delta_l2 = 0.43463`
  - `corr_tokenizer_cos_to_delta_cos = 0.29773`
- executed separation relates somewhat more closely to style gain:
  - `corr_style_code_sep_to_delta_idt_full = 0.62229`
  - `corr_executed_sep_to_delta_idt_full = 0.63518`
  - `corr_delta_sample_l2_to_delta_idt_full = 0.78297`
- latent/style-domain geometry is still stronger than tokenizer geometry as a predictor of executed geometry:
  - `corr_latent_l2_to_delta_l2 = 0.92695`
  - `corr_latent_cos_to_delta_cos = 0.72945`

So the packet does **not** isolate a renderer-only law; it only says executed behavior is the nearer explanatory layer than raw code geometry in this specific `L`-family probe.
