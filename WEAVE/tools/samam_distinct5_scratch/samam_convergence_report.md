# SaMam 从头训练收敛曲线评估报告

## 1. 实验概述

- **实验目的**：调查SaMam收敛曲线中间跳变问题，从头训练验证收敛稳定性
- **训练配置**：
  - 数据集：wikiart_distinct5_samam_512（5风格: Early_Renaissance, Impressionism, Minimalism, Rococo, Ukiyo_e）
  - 训练集：5000张content + 150张style
  - 测试集：classview结构，每风格30 content × 5 style_ref = 750张评估图
  - 迭代步数：7000步
  - Batch size：1
  - 图像尺寸：512×512
  - 精度：32-true
  - Checkpoint保存间隔：每250步
  - Lambda1=70, Lambda2=1
  - gradient-checkpointing=1, identity-gradient-checkpointing=1
  - 环境：WSL2 Ubuntu-22.04, samam312 venv (torch 2.4.0+cu121, mamba_ssm 2.2.4, pl 2.4.0)
  - 硬件：远程 3060 12GB
- **训练耗时**：3:52:13 (WALL_SECONDS=13948.61)，2026-07-01 13:19:59 → 17:12:30
- **评估耗时**：~2h8min，18:09 → 20:17
- **评估指标**：CLIP-S (open_clip, ViT-B/32), LPIPS (alex, v0.1)
- **总checkpoint数**：28个（step=000250 ~ step=007000）+ last.ckpt

## 2. 关键发现

### 2.1 跳变问题已消除

从头训练的收敛曲线**完全平滑**，没有之前的诡异跳变。说明跳变问题是之前训练配置或checkpoint继承导致，从头训练可解决。

### 2.2 收敛趋势

| 指标 | step=250 | step=3500 | step=4750(最低) | step=7000 | 趋势 |
|------|----------|-----------|-----------------|-----------|------|
| content_lpips | 0.8442 | 0.3544 | **0.3117** | 0.3209 | 平滑下降后稳定 |
| clip_style | 0.5819 | 0.6168 | 0.6174 | **0.6248** | 平滑上升 |
| clip_content | 0.6246 | 0.8699 | 0.8852 | **0.8785** | 快速上升后稳定 |

### 2.3 收敛阶段分析

1. **快速下降期**（step 250-3500）：LPIPS从0.844→0.354，CLIP-S从0.582→0.617，CLIP-C从0.625→0.870
2. **最优区间**（step 4250-4750）：LPIPS达到最低0.3117，CLIP-C达到最高0.8852
3. **稳定期**（step 5000-7000）：LPIPS在0.32-0.35轻微波动，CLIP-S/CLIP-C基本稳定
4. **结论**：模型在step 4250-4750已接近收敛，step 7000为最终稳定点

### 2.4 last.ckpt验证

last.ckpt的指标与step=7000完全一致（LPIPS=0.3209, CLIP-S=0.6248, CLIP-C=0.8785），确认last.ckpt就是step=7000的副本。

## 4. 时间统计

- **训练时间**：13948.61秒 = 3小时52分13秒
- **推理评估时间**：28个checkpoint × 750张图 = 21000张图
  - 平均推理耗时/checkpoint：~205秒（step 250-5500），后期~250秒
  - 平均指标计算耗时/checkpoint：~65秒
  - 总评估时间：~2小时8分钟
- **训练+评估总耗时**：~6小时

## 5. 结论与后续

1. **跳变问题已解决**：从头训练的收敛曲线平滑稳定，无诡异跳变
2. **模型在step 4250-4750已接近最优**：LPIPS最低0.3117，CLIP-C最高0.8852
3. **step 5000后进入稳定期**：指标波动小，LPIPS在0.32-0.35，CLIP-S在0.62-0.63
4. **建议**：
   - Dashboard收敛曲线使用此数据替换旧的有跳变的曲线
   - 可以考虑使用step=4750作为early-stop点（LPIPS最优）
   - 或使用step=7000作为最终模型（稳定收敛点）
