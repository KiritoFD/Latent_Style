# 实验反思与理论修正

## 反思 1：为什么 OMF-0 失败了？

### 理论预测
OMF 模式应该获得 style ≥ 0.69（超过 flow_matching），因为 SWD 直接匹配分布，没有 OT 耦合的模糊化。

### 实际结果
style = 0.667，比 flow_matching 的 0.69 更差。

### 根因分析

| 配置项 | 预期值 | 实际值 | 倍数偏差 | 影响 |
|--------|--------|--------|:--------:|------|
| `terminal_swd_weight` | 20.0 | 0.15 | 133× 太小 | SWD 仅贡献 2.3% 加权损失 |
| `w_low_freq` | 0 (D0 config) | 1.0 | N/A | low_freq 贡献 89% 加权损失 |
| `skip_routing_mode` | "add_proj" | "none" | N/A | 模型容量减半 |
| `sem_attn_temperature` | 0.12 | 0.08 | 0.67× | 注意力分布过于集中 |

**损失分解（OMF-0，第 12 epoch）**：
```
raw_swd = 0.0113 / 0.15 = 0.0753
raw_kin = 0.0354 / 1.5  = 0.0236
raw_low = 0.4353 / 1.0  = 0.4353
raw_cyc = 0.0033 / 1.0  = 0.0033

加权损失占比：
  low_freq:   0.4353 × 1.0  = 0.4353  (89.1%)
  kinetic:    0.0236 × 1.5  = 0.0354  (7.2%)
  terminal:   0.0753 × 0.15 = 0.0113  (2.3%)
  cycle:      0.0033 × 1.0  = 0.0033  (0.7%)
```

### 教训

1. **配置文件验证**：永远不要假设 `config.json` 是正确的。必须与已知正确配置交叉验证。
2. **损失监控**：训练时应监控 `加权损失占比`，确保主导损失是任务所需的。
3. **根目录 `config.json` 不可靠**：D0 配置（来自 ablation_destructive_7epoch）是已知正确的基线。

## 反思 2：Flow Matching 模式为何有上限？

### 初始理论
Flow matching 的 Brownian bridge + OT 耦合应该可以逼近任意分布。

### 实验观察
9/11 实验都在 0.678-0.692 范围。无例外。

### 修正后理论

Sinkhorn 最优传输（带熵正则 $\epsilon > 0$）产生**严格正耦合矩阵**：
$$P_\epsilon(i,j) = \exp((u_i + v_j - C_{ij})/\epsilon) > 0$$

每个内容样本的匹配目标是**所有风格样本的凸组合**：
$$\hat{z}_T^i = \sum_j P_\epsilon(i,j) \cdot z_s^j$$

凸组合始终位于风格样本凸包内部。极端风格特征（需要走到凸包边缘的路径）永远无法被精确匹配。

**关键见解**：这不是超参数问题，是**建模假设限制**。Flow matching + Sinkhorn OT 生成的路径永远在"均值化"的风格目标之间。要突破此限制，必须改变建模方式（如 OMF）。

### 后续影响

→ 停止 flow_matching 模式实验
→ OMF 模式是唯一可行的路径

## 反思 3：D0 vs K1 差距

### 现象
- D0（完全正确的 D0 配置）：style=0.701
- K1（grid search 最优）：style=0.716

**相同比率**：$\lambda_{swd}/\lambda_{kin} = 20$

### 差异源头

| 因素 | D0 | K1 (best) |
|------|:---:|:---------:|
| batch_size | 108 | 未报告 |
| **其他超参数** | 固定 | **最优组合** |
| 随机种子 | 1 | 多种 |

K1 的 0.716 来自 108 个配置的 grid search（Grid 39/108，39 个采样点），选择最优。这不是"配置 K1 确定产生 0.716"，而是"108 个配置中最优的那个达到了 0.716"。

**统计推断**：最优配置对应一个"运气"较好的超参数组合。D0 配置（我们的基线）是 grid search 的其中一个点。如果我们的 D0 复现达到 0.700-0.705，则说明 K1 的最优不是由单点配置保证的，而是 grid search 的极值统计。

**实验设计修正**：我们不需要复制 K1 的具体配置（未知），而是通过系统实验找到我们自己的最优组合。

## 反思 4：熵门控是否真的有效？

### 理论先验
熵门控在概念上优于均匀动能：
- 均匀动能：$\mathcal{L} = \lambda \cdot \|v\|^2$（所有像素相同惩罚）
- 门控动能：$\mathcal{L} = \lambda \cdot \|v\|^2 \cdot (1 + \gamma e(x))$（自适应惩罚）

### 潜在风险

1. **注意力度量不可靠**：注意力熵 $e(x)$ 可能不准确反映内容敏感性。如果模型"过度自信"（低熵但内容敏感），门控会误放运动。

2. **门控与温度冲突**：$\tau=0.12$ 的注意力温度产生特定熵分布。如果 $\tau$ 太小（我们错误的 0.08），所有区域熵都很低，门控无效。如果 $\tau$ 太大，所有区域高熵，门控过度。

3. **梯度噪声**：注意力熵本身由随机注意力计算，有噪声。熵图 $e(x)$ 的方差可能导致不稳定的梯度。

### 验证策略
- Phase 1 (K0p5_W20_ent2) 直接对比熵门控 vs 无门控
- 如果风格提升但 LPIPS 未恶化 → 验证门控有效
- 如果风格未提升 → 检查注意力熵分布（`attn_entropy` 监控）

## 反思 5：动能损失的建模假设

### 原始假设
动能损失 $\mathbb{E}[\|v\|^2]$ 约束路径长度，从而约束内容变化。

### 数学缺陷

动能损失惩罚的是**路径上的速度场**，不是终点位置：
$$\mathcal{L}_{kin} = \int_0^1 \mathbb{E}[\|v_\theta(z_t, t)\|^2] dt$$

但内容损失（LPIPS）仅依赖于终点：
$$\mathcal{L}_{content} = LPIPS(Dec(z_1), Dec(z_0))$$

两者通过 Jensen 不等式间接关联：
$$\|z_1 - z_0\|^2 \leq \int_0^1 \|v_t\|^2 dt$$

但 $\|z_1 - z_0\|^2$ 与 $LPIPS(Dec(z_1), Dec(z_0))$ 的关系在潜空间中非线性（因为 Decoder 和 LPIPS 的 VGG 特征提取都是非线性的）。

### 修正方案

**短期**：接受动能作为内容损失的粗糙代理，通过熵门控改善其精确性。

**长期**：考虑直接将终端约束放入损失函数：
- $\mathcal{L}_{low}(z_1, z_0)$ — 已在 D0 中但设为 0
- $\mathcal{L}_{LPIPS\_latent}(z_1, z_0)$ — 需要研究潜空间内容量度
- $\mathcal{L}_{color}(z_1, z_0)$ — 颜色直方图保持

## 反思 6：SWD 弱点的理论分析

### SWD 的局限性

SWD 是一个分布距离度量，但它：
1. **不感知语义**：所有特征维度和投影方向等权。风格相关和无关的维度同样对待。
2. **无样本对应**：SWD 匹配分布，但个体样本可能无意义——输出可能是不同风格的混合。
3. **投影效率**：随机投影在高维空间中效率低。d=256 时，需要大量投影才能达到 1/√d 的相对精度。

### 对 CLIP 风格分数的影响

CLIP 分数仅在语义层面测量"风格方向"。如果 SWD 优化的方向与 CLIP 风格方向不完全对齐，优化 SWD 可能无法最大化 CLIP 分数。

**理论偏差**：
- SWD 优化所有特征方向
- CLIP 分数仅关心特定方向（沿"风格"方向在 CLIP 空间中的变化）

**缓解措施**：$\lambda_{swd}$ 越大，SWD 越严格，模型输出的"风格度"越高。但边际收益递减。

## 反思 7：实验设计方法论

### 初始策略（错误）
1. 生成配置
2. 训练
3. 看结果
4. 调整

**问题**：没有反馈回路，根因分析不足。

### 修正后策略
1. **理论推导**：写数学模型，形式化假设和预测
2. **生成配置**：基于理论设计实验
3. **训练**：运行实验
4. **诊断**：如果结果偏离预测，解析损失分解
5. **理论修正**：找到建模假设的偏差
6. **回到 1**：修正后的理论指导新实验
